# Clay QR Studio — مُنشئ رموز QR والباركود

أداة ويب ثابتة (بلا خادم) لإنشاء رموز QR بأنواعها والباركود، مع قارئ رموز مدمج، بثيم **Clay Dark UI** الطيني الداكن.

**الصفحة الرئيسية:** `index.html` (الإصدار 4.0). الملفان `new.html` و`newq.html` نسختان قديمتان محفوظتان للرجوع إليهما.

## المزايا

- **أنواع QR متقدمة** (زر «خيارات متقدمة»): نص/رابط، ملف → رابط دائم، شبكة Wi-Fi، جهة اتصال vCard، بريد إلكتروني، رسالة SMS، اتصال هاتفي، واتساب، موقع جغرافي، حدث تقويم، حساب اجتماعي، تطبيق في المتجر.
- **ملف → رابط دائم → QR**: ارفع أي ملف (PDF، صور، مستندات، صوت، فيديو، ملفات مضغوطة… حتى 25 MB) ويُحوَّل إلى رابط سحابي ثابت ثم إلى رمز QR.
- **باركود** بإحدى عشرة صيغة (Code 128، EAN-13، EAN-8، UPC-A، UPC-E، Code 39، Code 93، ITF-14، Codabar، MSI، Pharmacode).
- توليد دفعة واحدة (سطر لكل رمز)، معاينة مباشرة، تخصيص الألوان والتدرج ونمط النقاط والشعار، تصدير PNG عالي الدقة و SVG، وتنزيل الكل في ZIP.
- قارئ رموز من صورة أو الحافظة أو الكاميرا.

## كيف تبقى الملفات دائمة؟

يُرفع الملف من المتصفح مباشرة إلى **Supabase Storage** (الخطة المجانية) في حاوية عامة:

1. تُحسب بصمة SHA-256 لمحتوى الملف في المتصفح.
2. يُحفظ الملف باسم `f/<بصمة>.<امتداد>`، فالملف نفسه يعطي دائمًا الرابط نفسه ولا يُرفع مرتين.
3. سياسات RLS على الحاوية تسمح بالإدراج فقط؛ **لا يمكن لأحد تعديل الملف أو حذفه أو سرد الملفات عبر الـ API**، لذا لا يتغير الرابط المطبوع في رمز QR أبدًا.
4. أنواع HTML/SVG/JS مرفوضة على مستوى الحاوية لمنع استضافة صفحات خبيثة.
5. ملف `.github/workflows/keepalive.yml` يرسل طلبًا كل ثلاثة أيام حتى لا يوقف Supabase المشروع المجاني بسبب الخمول.

يُحفظ سجل الروابط التي رفعتها في متصفحك فقط (localStorage) مع إمكانية تصديره JSON.

> ملاحظة خصوصية: كل من يملك الرابط يستطيع فتح الملف، فلا ترفع ملفات حساسة.

## الإعداد

- **التخزين:** القيم في `config.js` (`url` و`key` و`bucket`). المفتاح من نوع publishable وهو مصمَّم ليكون عامًا؛ الحماية من سياسات RLS.
- **لنقل التخزين إلى مشروع Supabase آخر:** طبّق `supabase/migrations/20261009_qr_files_public_bucket.sql` على المشروع الجديد ثم حدّث `config.js`.
- **الثيم:** رموز Clay Dark UI في `tokens.css` (ألوان، وصفات الظلال، المكوّنات `.clay-*`).

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق الرئيسي |
| `tokens.css` | رموز ومكوّنات ثيم Clay Dark UI |
| `storage.js` | رفع الملفات وإرجاع الرابط الدائم (fetch + WebCrypto بلا مكتبات) |
| `config.js` | إعدادات التخزين السحابي |
| `supabase/migrations/*.sql` | إنشاء الحاوية وسياساتها |
| `.github/workflows/static.yml` | النشر على GitHub Pages |
| `.github/workflows/keepalive.yml` | إبقاء مشروع التخزين المجاني نشطًا |
